句间 JUJIAN翻译服务设置

TRANSLATION

翻译来源

选择查词浮框显示哪些来源。默认词典始终保留，隐藏不会删除缓存或生词记录。

浮框展示

展开时才查询，隐藏后不查询

默认词典

沿用当前在线词典与翻译服务，并使用本地缓存。它不是完整的离线词典，不需要额外配置。你可以在上方控制它是否展示。

配置来源

密钥仅保存在当前扩展本机存储，不显示在视频中，也不包含在生词本导出里。留空保留原密钥；更换地址或服务类型需重新填写或清除。

配置范围

AI 支持采用 Chat Completions 请求和响应格式的接口；词典支持 URL 中带 {text} 的 GET 请求，以及点号 JSON 路径，例如 data.translation。不包含需要专有签名、SDK 或特殊请求体的接口。

各来源独立查询和显示结果。隐藏的来源不查询；展示但未配置的来源会提供设置入口。默认展开来源在查词时自动查询，其他来源点击展开后查询。测试会发送 hello，可能产生服务费用；开启上下文时附带示例句。

保存启用配置时，Chrome 会请求访问你填写的 API 域名。只将密钥和查询内容发送给你信任的服务。
