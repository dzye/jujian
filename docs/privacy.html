句间隐私说明

适用于 0.4.0 及其后保持相同数据处理方式的版本 · 更新日期：2026-10-27

句间是用于英文视频学习的 Chrome 扩展，由 GitHub 账号 dzye 维护。它提供字幕查词、词组翻译、来源收藏和手动遮挡功能。本说明描述扩展本身的处理方式，不代替视频网站和翻译服务商各自的隐私政策。

1. 本机保存的数据

扩展在 Chrome 本机扩展存储中保存设置、翻译来源配置、用户自行填写的 API 密钥、查询缓存、生词、词组、释义、备注、学习状态、字幕例句，以及用户主动收藏的视频标题、链接、时间点、平台标识和B站分 P/CID。这些数据用于提供学习功能，不是对全部浏览历史的后台收集。扩展不提供自建账号或云同步服务。

2. 何时发送数据

  • 使用默认词典时，所选英文单词会发送到 api.dictionaryapi.dev；所选单词或词组会发送到 api.mymemory.translated.net。查询结果可缓存在本机。
  • 使用用户启用的自定义 AI 或在线词典来源时，所选内容会发送到用户配置并授权的 HTTPS 接口。仅在用户启用“发送当前字幕句子”后，AI 请求才附带当前字幕句子。
  • API 密钥仅作为认证信息发送给用户配置的服务地址。密钥在本机保存，界面不回显；本机存储不是系统级密钥保险库。
  • 读取视频字幕时，扩展会与当前视频网站及其字幕服务通信。B站请求使用浏览器正常站点会话，不通过 Cookie API 读取、导出或向翻译服务发送站点登录 Cookie。视频标识与 CID 用于读取当前视频或分 P 的字幕。
  • 来源配置的测试按钮会向该服务发送 hello；若启用上下文，附带示例句。第三方服务可能计费或记录请求。

扩展不会将音视频文件、完整字幕文件或浏览器登录 Cookie 上传给翻译服务。生词本中的视频来源、备注等不作为默认查词请求的内容发送。扩展没有开发者自建的内容收集接口、广告或分析统计 SDK。

3. 展示与查询控制

隐藏的翻译来源不会发起新的查询。默认展开来源会在用户查词时查询，其他来源在展开时查询。关闭上下文选项可停止附带句子。自定义 API 的域名访问权限由用户在配置保存时授予；可以在 Chrome 扩展设置中撤销。

4. 数据用途与第三方

数据仅用于用户请求的字幕、翻译、收藏及设置功能。维护者不出售生词、视频来源、密钥或例句，不将其用于广告、信用评估或贷款用途。第三方翻译/AI 服务的数据保留和训练政策由相应服务商决定；请自行选择可信来源。

5. 删除、导入与导出

用户可以在生词本删除词条、编辑备注、导出 JSON/CSV 或导入合并。导出包括词条、例句、释义来源和视频时间链接，不包括 API 密钥或服务配置。用户可在翻译设置清除密钥、删除自定义来源；隐藏来源不等于删除配置或缓存。卸载扩展或清除其本机存储会删除扩展本机数据。导出文件由用户自行保管与删除。

6. 保留时间和安全

本机数据通常保留到用户删除、清除存储或卸载扩展为止；重装或更换未打包扩展路径可能产生不同的存储空间。对外查询使用 HTTPS。扩展不承诺对本机存储提供独立于 Chrome 配置文件的强加密，也无法控制第三方 API 的存储期限。

7. 联系与变更

问题和数据处理咨询可通过 GitHub Issues 提交，请勿在公开问题中粘贴密钥、账号 Cookie 或私人视频内容。数据处理方式发生变化时会更新本页面。
