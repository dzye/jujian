名称：句间 — 英文视频查词与生词本
分类建议：教育 / 语言学习（以后台实际选项为准）
语言：简体中文
主页：https://dzye.github.io/jujian/
支持：https://github.com/dzye/jujian/issues
隐私说明：https://dzye.github.io/jujian/privacy.html

## 详细说明

句间帮助你在英文视频里理解单词、词组，并保留遇见它们的真实语境。

- 支持 YouTube 与B站普通视频页的独立英文字幕。
- 点击单词查释义，拖选多个单词查询词组。
- 默认词典保留，翻译来源可显示、隐藏、排序和设置默认展开；其他来源展开时才查询。
- 可配置自有 AI 兼容接口或在线词典 API；不附带付费 API 服务或额度。
- 可选择悬停字幕自动暂停、移出继续播放，或使用播放器手动控制。
- 左右箭头跳到上一条/下一条字幕开头，字幕与视频同步。
- 调整字幕位置；手动遮挡视频中无法关闭的中文字幕。
- 生词本保存释义、例句、翻译来源、视频标题与时间链接。B站来源包含分 P 信息。
- 支持来源视频筛选、详情连续浏览，以及 JSON / CSV 导入导出。

使用方式：打开支持的视频页，点击扩展图标，在“字幕学习”中开启；没有独立英文字幕时可使用“手动遮挡”。

注意：并非所有视频都有独立英文 CC；部分B站字幕需要登录账号。番剧、直播、嵌入页、画中画、硬字幕识别不属于当前版本范围。机器翻译可能有语境误差。0.4.0 为体验版，兼容性和验证范围见项目说明。

隐私：学习数据保存在本机。查词会向启用的词典或用户配置的 API 发送所选内容；仅在用户启用上下文时附带当前句子。密钥与服务配置不包含在生词本导出中。完整说明见隐私页面。

## 单一用途

为用户正在观看的英文视频提供字幕学习、查词和带视频语境的生词收藏；遮挡与字幕定位功能服务于同一学习过程。

## 权限理由

- activeTab：用户点击扩展后，临时读取/控制当前视频页的字幕、播放状态与遮挡层。
- scripting：注入本地打包的平台适配器与学习 UI；B站读取器在页面环境使用正常站点会话读取字幕，不绕过登录限制。
- storage：保存学习设置、缓存、词条、语境和用户自行配置的服务凭据。
- api.dictionaryapi.dev 与 api.mymemory.translated.net：默认词典和翻译来源请求。
- optional_host_permissions https://*/*：允许用户配置不同的 HTTPS API。仅在用户保存启用的自定义配置时请求具体域名，不要求一次授权所有网站。

## 数据披露填表依据

实际处理的网站内容：所选字幕文本、可选当前句子、例句与视频标题。
实际处理的网页活动/来源：用户主动收藏的视频链接、标识和时间点，存于本机，不收集全部浏览历史。
实际处理的认证信息：用户自行填写的第三方 API 密钥，本机保存并用于配置域名的认证。
无开发者自建收集服务器、无广告/统计 SDK。不出售用户数据，不用于信用评估/贷款用途，不为与单一用途无关的目的使用或传输。
以上为事实填写依据，需按后台实际问题逐项勾选；不可勾选“完全不处理任何用户数据”。

## 审核操作说明

1. 在 YouTube 有英文 CC 的视频中开启字幕学习，点击单词/拖选词组，使用默认词典，无需开发者提供账号。
2. 打开生词本，检查收藏、视频时间来源和 JSON/CSV 导入导出。
3. 在B站普通视频页测试遮挡；英文 CC 可能要求审核员登录其本人账号。未登录时会明确提示，不绕过限制。
4. 自定义 AI/词典 API 是可选功能，默认词典可独立使用；审核员可使用自身服务测试。不要提供个人账号 Cookie 或私人付费密钥。
